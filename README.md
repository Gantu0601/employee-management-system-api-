# employee-management-system-api-
Production-ready Employee Management REST API built with Java, Spring Boot, Spring Security, JWT Authentication, PostgreSQL, Docker and # Employee Management System API

A production-ready Employee Management REST API built with Java and Spring Boot.

## 🚀 Tech Stack

- Java 21
- Spring Boot 3
- Spring Security
- JWT Authentication
- PostgreSQL
- Maven
- Docker
- Swagger (OpenAPI)

## 📋 Features

- User Authentication
- JWT Authorization
- Employee CRUD
- Search Employees
- Pagination
- Sorting
- Validation
- Global Exception Handling
- Docker Support
- API Documentation
